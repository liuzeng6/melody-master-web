# 应用截图使用说明

## 如何添加应用截图

1. **准备截图文件**
   - 支持格式：PNG, JPG, JPEG, WebP, GIF
   - 推荐尺寸：1080x2340 像素（9:19 宽高比）
   - 推荐格式：PNG（无损质量）

2. **放置截图**
   - 将截图文件放入 `public/images/` 目录
   - 文件名建议使用有意义的名称，例如：
     - `home.png`（首页截图）
     - `player.png`（播放器截图）
     - `playlist.png`（播放列表截图）

3. **自动显示**
   - 网站会自动读取 `public/images/` 目录下的所有图片
   - 截图会按照文件名字母顺序显示
   - 无需修改任何代码

## 示例

```
public/
└── images/
    ├── home.png
    ├── player.png
    ├── playlist.png
    └── settings.jpg
```

## 注意事项

- 截图数量不限，建议 3-6 张最佳
- 图片会自动适配响应式布局
- 移动端和桌面端会显示相同的截图
- 如果图片加载失败，会显示占位符
